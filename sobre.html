🩺 Sistema Web de Monitoramento de Saúde

Este Sistema Web foi desenvolvido como parte dos requisitos para a conclusão do curso de Graduação da UNIVEPS, na disciplina de Projeto Integrador VI. Sua principal funcionalidade é o acompanhamento de indicadores de saúde, como:

  • Pressão Arterial
  • Glicemia
  • Massa Corporal
  • Índice de Massa Corporal (IMC)
  • Circunferência Abdominal
  • Relação Cintura-Quadril

Os dados cadastrais dos usuários são armazenados em um banco de dados SQL, enquanto os registros de saúde são mantidos em arquivos CSV, utilizando uma estrutura no-SQL.

📊 O sistema permite a análise temporal e o monitoramento contínuo desses dados. Além disso, é possível gerar relatórios com tabelas e gráficos de evolução, que podem ser impressos ou compartilhados via WhatsApp ou e-mail.

👥 Essa ferramenta é útil não apenas para o próprio usuário acompanhar sua evolução em parâmetros antropométricos, pressão arterial e glicemia, mas também para profissionais da saúde que desejam acompanhar seus pacientes de forma prática e eficiente.
